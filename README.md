# Custom Gravity Falls Hackpad

A custom Gravity Falls-themed hackpad designed to encode and decode ciphers from the series.

## Features
* **Encode and decode** Gravity Falls ciphers
* **OLED display** for visual feedback
* **Rotary encoder** for menu navigation
* **Four switches** for mechanical input
* **Software** designed with Python
* **Custom-designed PCB** layout

## How I Built It
The hackpad uses a Seeed XIAO RP2040, an OLED screen, a rotary encoder, and four switches.

I designed the PCB myself using KiCad and wrote the software in Python. One of the biggest challenges was learning KiCad and finding the correct footprints for each component.
